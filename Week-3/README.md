# Week 3 - Advanced SQL Analytics Assignment

## Overview

This week focused on learning advanced SQL concepts used in data analysis and business reporting.

The assignment involved analyzing the Superstore dataset using Subqueries, Common Table Expressions (CTEs), and Window Functions to solve real-world business problems and generate customer sales insights.

---

## Topics Learned

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- PARTITION BY
- Business Analytics Queries
- Customer Sales Analysis

---

## Assignment

Advanced SQL Analytics using the Superstore Dataset

### Objectives

- Load raw sales data into a staging table
- Create customers, orders, and products tables
- Perform advanced SQL analysis
- Rank customers and products
- Generate business insights using SQL
