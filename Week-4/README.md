# Week 4 - Azure Cloud Fundamentals and Data Pipeline Implementation using Azure Data Factory

## Overview

This week focused on understanding Azure cloud fundamentals and implementing an end-to-end data pipeline using Azure Data Factory (ADF) and Azure Blob Storage.

The assignment involved building a cloud-based data pipeline that reads data from Azure Blob Storage, retrieves file metadata, copies the dataset to a destination container, and monitors the pipeline execution using Azure Data Factory.
