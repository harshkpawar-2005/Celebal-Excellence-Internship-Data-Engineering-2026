# Week 7 - Databricks & Delta Lake

## Overview

This week focused on understanding Databricks, Delta Lake, and modern data engineering practices for incremental data processing. The assignment demonstrates building Delta tables, implementing incremental data loading, performing MERGE operations (SCD Type 1), and validating the final dataset using Databricks and Apache Spark.

- Databricks Workspace
- Notebook & Cluster Management
- Delta Lake Fundamentals
- ACID Transactions
- Delta Table Versioning
- Fact & Dimension Modeling
- Incremental Data Processing
- MERGE (Upsert) Operations
- Slowly Changing Dimension (SCD Type 1)
- Data Layering Architecture
- Data Validation

## Assignment

### Delta Lake Incremental Data Processing

### Objectives

- Load a CSV dataset into a Delta table.
- Perform data cleaning and preprocessing.
- Create an incremental dataset.
- Apply Delta Lake MERGE operations.
- Update existing records.
- Insert new records.
- Validate the processed dataset.
- Understand incremental data processing using Delta Lake.
