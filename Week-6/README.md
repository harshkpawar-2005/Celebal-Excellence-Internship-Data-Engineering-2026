# Week 6 – Apache Spark Data Processing

## Overview

This week's assignment focuses on learning the fundamentals of Apache Spark and distributed data processing using PySpark. The project demonstrates reading data from CSV files, performing DataFrame transformations, handling missing values, applying aggregations, and storing processed data efficiently.

## Topics Covered

- Introduction to Apache Spark
- Spark Architecture
- SparkSession
- DataFrame API
- Schema Inference and Custom Schema
- Data Exploration
- DataFrame Transformations
- Filtering and Column Operations
- Handling Missing Values
- GroupBy and Aggregations
- Spark Actions
- Lazy Evaluation
- DAG (Directed Acyclic Graph)
- Narrow vs Wide Transformations
- CSV and Parquet File Formats

## Assignment

Implemented an end-to-end Spark data processing pipeline using the Superstore dataset with PySpark.

## Technologies Used

- Apache Spark
- PySpark
- Python
- Google Colab
- Jupyter Notebook
