# Apache Spark Data Processing Assignment

## Project Overview

This project demonstrates the use of Apache Spark for distributed data processing using the Superstore dataset. The assignment covers the complete workflow from loading raw data to performing transformations and writing processed data.

## Objectives

- Understand Apache Spark architecture
- Create and configure SparkSession
- Read CSV datasets using PySpark
- Explore DataFrames and schemas
- Apply DataFrame transformations
- Filter and manipulate data
- Handle missing values
- Perform aggregations using GroupBy
- Compare CSV and Parquet storage formats
- Understand Spark execution and optimization concepts

## Dataset

**Name:** Sample - Superstore.csv

The dataset contains retail sales information including orders, customers, products, sales, quantity, discounts, and profits.
